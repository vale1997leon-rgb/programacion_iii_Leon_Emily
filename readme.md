---

## 🧩 Tecnologías y conceptos

### 🌐 HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para crear la estructura de las páginas web. Permite definir elementos como títulos, párrafos, imágenes, enlaces, formularios y tablas.

### 🎨 CSS

**CSS (Cascading Style Sheets)** permite dar estilo y diseño a las páginas web. Se utiliza para controlar colores, tamaños, posiciones, fuentes, animaciones y la distribución de los elementos.

### ⚡ JavaScript

**JavaScript** es un lenguaje de programación utilizado para agregar interactividad y comportamiento dinámico a las aplicaciones web. Permite trabajar con eventos, funciones, objetos, datos y comunicación con servidores.

### 🔷 TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que facilitan el desarrollo de aplicaciones grandes y mantenibles.

### 🐈 NestJS

**NestJS** es un framework de Node.js utilizado principalmente para desarrollar aplicaciones y APIs del lado del servidor. Está basado en TypeScript y utiliza una arquitectura organizada mediante módulos, controladores y servicios.

### ⚛️ ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para crear interfaces de usuario. Permite construir aplicaciones mediante componentes reutilizables y gestionar de manera eficiente la interacción con el usuario.
